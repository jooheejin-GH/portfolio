🖼️ Visual Resizer ระบบแปลงสัดส่วนภาพอัตโนมัติ

อัปโหลด Key Visual ภาพเดียว → เลือกขนาดสื่อ → ได้ภาพครบทุกช่องทาง พร้อมวางโลโก้แบรนด์ตำแหน่งเดิมทุกไฟล์

  1. 1 · ภาพต้นแบบ (KV)ระบบเลือกต้นแบบที่สัดส่วนใกล้ขนาดเป้าหมายที่สุดให้เอง
  2. 2 · ขยายภาพด้วย AIของจริงใช้ Gemini ต่อฉากส่วนที่ขาด — เดโมนี้จำลองด้วย canvas (สะท้อนขอบ + เบลอ + ไล่เฉด)
  3. 3 · วาง CI Brandวางโลโก้ตาม template ต่อขนาด แล้วดาวน์โหลดทีเดียวทั้งชุด
